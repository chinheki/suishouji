# 随手记

包含首页、统计和设置的本地实验记录 PWA。标签分为实验条件和实验结果，点击即记一次，短暂显示撤销。两组都可新增标签。

## 本地运行

在此目录运行 `python3 -m http.server 4173 --bind 127.0.0.1`，打开 http://localhost:4173 。请始终使用相同地址和端口，浏览器数据库按来源隔离。

## 存储

IndexedDB 数据库 `suishouji`：`tags` 保存标签，`events` 保存每次事件的独立 ID、标签快照、UTC 时间、本地时区与偏移。写入事务完成后才显示成功；未点击不表示“没有发生”。首次建库预置 8 个标签，无演示事件。应用缓存与记录数据库分开，更新应用缓存不删除记录。

首次记录时申请持久存储，是否批准由浏览器决定。首次联网加载后支持离线使用。PWA 安装与 Service Worker 需要 HTTPS 或 localhost；在手机访问电脑的普通 HTTP 局域网地址不满足要求。

已实现首页、标签新增、事件记录、撤销、统计、标签管理和离线外壳。历史编辑、备份恢复尚未实现。清除网站数据会删除记录；更换浏览器、设备或站点地址不会自动迁移数据。

## 统计与标签管理

底部导航切换首页、统计、设置。删除标签仅写入 archived 标记，不删除标签 ID 或任何事件；可在设置页恢复；新增标签不允许与同组的已删除标签重名。统计支持多个条件、一个结果，已删除标签仍可选。点图横轴为本机时区的发生时间，每个事件一个点，同一位置附近的事件纵向堆叠避免遮盖；按月或全部查看，逐项显示次数，点击圆点查看详情。未记录不视为否定结果，图表不推断因果。

## 实验条件与结果的名称和周期（2026-09-30）

- 每次点击从数据库读取该标签和最近一次发生时间。同一读写事务内完成检查与写入，防止连点或多页面并发。未满周期不新增事件，提示下次可记录时间；恰好到期即可记录。撤销最新事件后依据剩余历史重新判断。

## 时间戳统计标记（2026-09-30）

所有标签每次点击都会保存 `occurredAt`（UTC ISO）、时区和偏移，无论是否勾选「时间戳」。此选填选项仅用于标记统计关注点：例如入睡、起床关注发生时刻；一般事件关注发生次数。该选项不控制时间采集，也不改变首页标签的展示和点击行为。

条件与结果共用同一选项，默认关闭。为兼容已保存数据，字段仍叫 `timestampEnabled`，语义为统计时关注发生时刻；事件保留该标记快照。设置页显示“按时刻统计”。撤销规则不变。已移除上一版本在首页标签下显示最近时间的设计；不删除任何记录。离线缓存升至 v7。

当前统计仍为统一的发生时间点图；已保留该标记供后续区分次数统计和时刻趋势使用，尚未实现专门的时刻趋势图。

此前 25 项数据库检查通过。本次仅纠正选项语义、说明和首页显示，不改记录及周期检查逻辑。

## 时间戳的特殊周期规则（2026-09-30）

- 勾选时间戳时自动启用实验周期并选择每日（1 天）；条件和结果共用此行为。仍可调整周期或关闭周期。
- 时间戳标签的周期表示统计分组意图，不限制记录次数；同一天、同一周期内可以保存多条独立记录，全部保存各自发生时间。当前点图仍逐条展示，尚未实现按此周期分组的专用时刻趋势图。
- 普通标签继续按最近一次记录检查周期、拦截重复。取消时间戳后，当前选择的周期恢复普通防重复语义。
- 已有时间戳标签不批量改写周期配置，但同样不再拦截重复；撤销只删除选中的那一条事件。
